# CMO Dashboard — Hata & Düzeltme Logu
**Tarih:** 14 Mayıs 2026

## ✅ Çözülen Sorunlar

### 1. OmniSocials CORS Hatası (Failed to fetch)
- **Sorun:** Dashboard, OmniSocials API'yi doğrudan tarayıcıdan çağırıyordu → CORS bloğu
- **Çözüm:** Flask proxy eklendi (`gsc_api_server.py`). Tüm OmniSocials çağrıları `localhost:8765/api/omni/*` üzerinden geçiyor
- **Durum:** ✅ Proxy çalışıyor

### 2. OmniSocials GET /posts → 403 Forbidden
- **Sorun:** `GET https://api.omnisocials.com/v1/posts` endpoint'i **mevcut değil** — OmniSocials publishing-only API
- **Mevcut endpoint'ler:** `GET /accounts`, `POST /posts/create`, `POST /posts/create-and-publish`, `POST /media/upload`
- **Çözüm:** `/api/omni/posts` proxy'si Supabase `social_posts` tablosuna yönlendirildi
- **Durum:** ✅ Düzeltildi (server yeniden başlatılınca aktif)

### 3. OmniSocials GET /media → 403 Forbidden
- **Sorun:** Aynı sebeple `/media` endpoint'i de mevcut değil
- **Çözüm:** `/api/omni/media` proxy'si Supabase `media_library` tablosuna yönlendirildi
- **Durum:** ✅ Düzeltildi

### 4. Flask Server Başlatma Sorunu
- **Sorun:** Server `localhost:8765`'te çalışmıyordu → "Failed to fetch"
- **Başlatma komutu:** `python gsc_api_server.py` (proje root'undan)
- **Durum:** ✅ Çalışıyor

## ⚠️ Tespit Edilen Ama Henüz Düzeltilmemiş Sorunlar

### 5. JavaScript Veri Şekli Uyuşmazlığı (ÖNEMLİ)
- **Sorun:** `cmo-dashboard.html` içindeki `fetchOmniPosts()` → `json.data` bekliyor
- **Proxy'nin döndürdüğü:** `{ "posts": [...], "source": "supabase" }`
- **Etki:** Post listesi boş görünüyor, sayaçlar 0 kalıyor
- **Çözüm gereken:** HTML'deki `json.data` → `json.posts` olarak güncellenmeli
- **Aynı sorun:** `fetchOmniMedia()` → `json.data` bekliyor, proxy `json.media` dönüyor

### 6. Supabase Tabloları Oluşturulmadı
- **Sorun:** `social_posts` ve `media_library` tabloları Supabase'de yok → proxy boş array dönüyor
- **Çözüm:** `supabase-setup.sql` çalıştırılmalı
- **Supabase URL:** `https://supabase.turklawai.com`

### 7. Google PageSpeed API — CORS / Proxy Hatası
- **Sorun:** Dashboard PageSpeed API'yi direkt browser'dan çağırıyor → "API yanıt vermedi"
- **Çözüm gerekiyor:** PageSpeed de Flask proxy'ye taşınmalı (`/api/pagespeed` endpoint)

### 8. GA4 / GSC Pipeline — Credentials Eksik
- **Sorun:** `05-gsc-nocodb/` pipeline için GSC credentials JSON yok
- **Gerekli:** `GSC_CREDENTIALS_PATH` env değişkeni + service account JSON
