## 1. GEO = AI Caginda SEO

Geleneksel SEO kurallari gecerli ama yetersiz. GEO ek kurallari:

| Geleneksel SEO | GEO (AI Gorunurluk) |
|----------------|---------------------|
| Google'da sira | ChatGPT/Claude/Gemini'de alinti |
| Anahtar kelime | Dogal dil sorgulari |
| Backlink | Ucuncu taraf kaynaklar (Wikipedia, Reddit) |
| Meta title | Icerik yapisi ve net yanitlar |
| Link juice | AI guven skoru |

## 2. Niyet Bazli Icerik Stratejisi

### Bilgi Arayan (Awareness)
- **Icerik:** Blog, rehber, egitim
- **Ton:** Egitici, sabirli
- **CTA:** Newsletter, ucretsiz test
- **Ornek:** "GEO nedir?", "ChatGPT'de nasil gorunurum?"

### Urun Arayan (Consideration)
- **Icerik:** Landing page, hizmet sayfasi, karsilastirma
- **Ton:** Net, kararlandirici
- **CTA:** Teklif iste, iletisime gec
- **Ornek:** "GEO hizmeti", "AI SEO ajansi"

### Karsilastirma Yapan (Decision)
- **Icerik:** Vaka calismasi, ROI hesabi, referans
- **Ton:** Kanit odakli, seffaf
- **CTA:** Ucretsiz analiz, demo
- **Ornek:** "SEO vs GEO", "Botfusions vs diger ajanslar"

## 4. Icerik Yapisi (AI Alinti Icin)

### AI'nin alintilayacagi yapi:
```
[Net tanim] → GEO, markalarin AI araclarinda gorunmesini saglar.
[Somut ornek] → Ornegin, %527 trafik artisi gordugumuz musteri vakamiz var.
[Adim adim] → 1. Analiz 2. Strateji 3. Optimizasyon 4. Raporlama
[Kaynak/kanit] → botfusions.com/geo-hizmet
```

### AI'nin SEVMEDIGI yapi:
- Dolambacli girisler ("Bugun dunyasinda...")
- Jargon tekrari ("Innovasyon, dijital donusum, sinerji...")
- Net olmayan ifadeler ("belki", "olabilir", "genellikle")

## 6. Teknik SEO Checklist (GEO)

- [ ] Schema markup (Organization, Service, FAQ)
- [ ] Structured data (JSON-LD)
- [ ] H1: Marka + Hizmet + Fayda
- [ ] Meta description: Net deger teklifi + CTA
- [ ] Sayfa hizi < 3s (AI crawler'lar hizli sayfalari tercih eder)
- [ ] HTTPS zorunlu
- [ ] Mobil uyumlu
- [ ] Internal linking: pillar → destekleyici
- [ ] FAQ bolumu: AI'nin yanitlayacagi soru formati
