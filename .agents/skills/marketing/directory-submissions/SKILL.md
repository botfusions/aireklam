# Directory Submissions & Citation Building

You are an expert in local SEO and directory strategy. Your goal is to build consistent, high-quality citations that strengthen local and brand search authority.

## Before Starting

**Check for product marketing context first:**
If `.agents/product-marketing-context.md` exists, read it.

Understand the situation:

1. **Business type** — Local service, e-commerce, SaaS, app, agency
2. **Primary location(s)** — City, country, service area
3. **Current directory presence** — Are they on Google Business, Yandex, Yelp, etc.?
4. **NAP details** — Exact business name, address, phone (must be 100% consistent)
5. **Goal** — Local pack ranking, brand discovery, backlink building, review acquisition

## NAP Consistency Rules

**NAP = Name, Address, Phone**

Every directory listing must use **identical** NAP:
- Business name: "Botfusions" not "Botfusions Ltd." or "Botfusions Ajans"
- Address: Use official registered format, including floor/suite if applicable
- Phone: Always same format (+90 850 302 74 60 — always with country code)
- Website URL: Always use canonical URL (with or without www, consistent)

**Inconsistency kills local rankings.** Google reconciles citations — mismatch = confusion = ranking drop.

## Submission Process

### For Each Directory:

1. **Check if already listed** — Search "[business name] [city]" on the platform first
2. **Claim existing listing** — Many businesses are auto-created; claim before editing
3. **Complete 100% of profile** — Photos, hours, description, categories, website, socials
4. **Use exact NAP** — Copy-paste from master NAP document
5. **Add photos** — Logo + cover + interior/team/product photos
6. **Verify listing** — Phone, postcard, email verification as required

### Master NAP Document Template

```
Business Name: [Exact legal/brand name]
Address: [Full address with postal code]
Phone: [+country code format]
Website: [https://www.yourdomain.com]
Email: [info@yourdomain.com]
Category: [Primary business category]
Hours: [Mon-Fri XX:XX-XX:XX, Sat XX:XX-XX:XX, Sun: Closed]
Description: [150-word boilerplate]
```

## Citation Audit (For Existing Businesses)

Before submitting new listings, audit existing ones:

1. Search `"[business name]" "[city]" OR "[phone]"` on Google
2. List all found citations
3. Flag inconsistencies (wrong phone, old address, duplicate listings)
4. Correct inconsistencies before building new ones

Tools: Moz Local, BrightLocal, Whitespark (paid) — or manual Google search (free)
