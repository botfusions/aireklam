ISO Certification — A Critical Difference for Technical Content

For many buyers of technical or legal translation, ISO 17100 certification is a procurement requirement, not a preference. It defines the minimum qualifications for translators and revisers, requires a documented review step for every translation, and mandates a quality management system subject to external audit.

Alafranga holds ISO 17100:2015 certified by Bureau Veritas — one of the world's largest independent certification bodies. Turkish Translators does not publicly state ISO 17100 certification. For organisations in regulated sectors (CE marking, compliance documentation, medical translation, engineering handbooks), the absence of a stated certification is a meaningful risk factor.

Bilingual Only vs Full Programme Capability

Turkish Translators operates exclusively in the Turkish–English language pair. This is a legitimate specialisation model, but it creates a hard ceiling: any project that extends beyond Turkish and English requires a different vendor. For organisations where Turkish is one language in a wider multilingual programme — common in European industrial and technology companies — this limitation means managing multiple vendor relationships.

Alafranga's 40+ language portfolio was built around real client demand, not catalogue expansion. Dutch, German, French, Arabic, and other languages were added because existing Turkish clients asked for them. The result is a multilingual delivery infrastructure that shares glossaries, terminology databases, and project management across language pairs — reducing review time and terminology inconsistency across a programme.

Technology Infrastructure — CAT Tools, TMS, AI

Professional-grade technical translation relies on translation memory (TM), terminology management, and CAT tool consistency. Without a TMS, every project starts from scratch: no leverage on previously translated segments, no terminology enforcement, no integration with client systems.

Alafranga has operated Project Open (an open-source TMS) since 2007, MemoQ and SDL Trados for CAT tool workflows, and its own SmartEdit AI system for AI-assisted tiers. This infrastructure is directly visible in their vendor network statistics: 9,500+ purchase orders tracked since 2009, with performance data on every translator.

Turkish Translators' website does not describe a TMS or CAT tool infrastructure. For one-off documents this may be acceptable. For repeat technical content — machinery manuals updated annually, software UI strings revised quarterly, compliance documents maintained over years — the absence of a TM system means paying full price for already-translated content every time.

Alafranga's structure — 5,200+ registered translators, 484 with verified history, TMS, AI-assisted tiers, and multilingual programme experience — is designed for exactly that scaling scenario.
